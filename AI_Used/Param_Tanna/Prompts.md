# Prompts

These are the prompts I gave Claude Code during my work on this project, in
order. They are lightly cleaned for spelling but otherwise as I typed them.

## Understanding the project and the repo
1. Told it we picked Project 7 ("Extending Kubernetes self-healing for network
   failures"), pasted our team's planning discussion, and asked it to explain
   the whole project to me since I was new to Kubernetes, and how I should
   explain it.
2. "I cloned it, read through the repo." (asked it to read the actual code)
3. Asked what everyone had done, which module was mine, and what the repo
   permissions were.

## Building my module
4. "I need to complete the whole module today nicely and also push it... and
   also review others' work afterwards for what can be improved so we get good
   grades."
5. Walked through installing Go (it gave me the commands, I ran them and pasted
   the output).
6. Pasted the build/test output back several times so it could see the results.

## Git and the pull request
7. A series of step-by-step git prompts: I asked it to teach me the flow one
   command at a time (branch, add, commit, push, PR) because I wanted to learn
   git properly and do it myself.
8. "give the content for the PR so I'll create the pull request."
9. Asked what CI is and how it works, in this project.

## Quality checking
10. "check the code and everything... does the project function properly?"
11. Asked it to review what everyone did and their repo permissions.

## Report and this disclosure
12. Asked it to add a Computer-Networks point of view to the existing LaTeX
    report without erasing what was there, and to build this AI usage folder.
