# Tools

**Tool used:** Claude Code (Anthropic), running the Claude Opus model.

**What it is:** Claude Code is an AI coding assistant that runs in the terminal.
Beyond chatting, it can read and edit files in the repo, run shell commands
(build, test, git), and read command output back. I ran it inside my WSL Ubuntu
/ Windows setup, pointed at my local clone of the project.

**How I accessed it:** through the terminal, in my project folder
`D:\Sem 5\CN\CS331-CN-Project-1`.

**Where I used it:** only for my own part of the project — the NetworkPolicy
module — plus understanding the shared codebase, verifying the build, learning
the git/PR workflow, and later adding the Computer-Networks framing to the
report.

I did **not** use any other AI tool (no ChatGPT, Copilot, Gemini, etc.) for my
part.
