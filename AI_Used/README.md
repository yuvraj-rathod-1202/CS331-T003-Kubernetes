# AI Usage Disclosure

This folder documents the use of AI tools in our CS331 Computer Networks project
("Extending Kubernetes Self-Healing for Networking Failures"), as required for
the submission.

Each team member documents their own AI usage in their own subfolder. This
subfolder is for **Param Tanna (24110236)** and covers the four items asked for:

- `Tools.md` — which AI tool was used
- `Prompts.md` — the prompts I gave
- `Thought_Process.md` — how I integrated AI into my workflow
- `Step_by_Step.md` — where and how AI contributed at each stage
- `Conversation.md` — the (curated) transcript of my session with the tool

The transcript has been trimmed to the parts relevant to this CN project;
unrelated coursework, personal notes, and repeated network-retry noise from a
flaky campus connection have been removed for readability. Nothing about who did
what has been altered.
